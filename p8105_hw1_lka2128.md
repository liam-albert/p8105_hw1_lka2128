## Question 2

Create a data frame comprised of:

- a random sample of size 10 from a standard Normal distribution
- a logical vector indicating whether elements of the sample are greater
  than 0
- a character vector of length 10
- a factor vector of length 10, with 3 different factor “levels”

**Building a data frame:**

``` r
df = tibble(
random_sample = rnorm(10),

logical_vec = random_sample > 0,

character_vec = c("a", "b", "c", "d", "e", "f", "g", "h", "i", "j"),

factor_vec = factor(c("A", "B", "C","A", "B", "C","A", "B", "C","A"))
)

df
```

**Variable conversion**

``` r
as.numeric(pull(df,logical_vec))

as.numeric(pull(df,character_vec))
```

    ## Warning: NAs introduced by coercion

``` r
as.numeric(pull(df,factor_vec))
```

### Explanation

These `mean` command works for these values because random_sample is
already numeric, and R treats logical_vec as a binary of 1=true and
0=false. When we run the same command on character variables, we are
returned with an `NA` and warning message. By applying `as.numeric` to
the factor_vec we can convert the values to represent the 3 levels. This
shows that R can calculate a mean when values are numeric and although R
can convert factor vectors to numeric type, the values are not
meaningful, so taking their means would not have any interpretation.
